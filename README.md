# npm Dependency Graph Visualizer

Вариант 18 по практической работе по конфигурационному управлению.
Проект строит граф зависимостей npm-пакета и сохраняет его в PNG.
Метаданные npm читаются напрямую по HTTP средствами стандартной библиотеки
Python. npm CLI и сторонние библиотеки для получения зависимостей не нужны.

## Требования

- Python 3.10 или новее.
- Graphviz `dot` в PATH для создания PNG (этап 5).
- npm не требуется для работы приложения.

## Запуск

Windows:

```bat
run.bat --package left-pad --repository https://registry.npmjs.org
```

Linux или macOS:

```sh
./run.sh --package left-pad --repository https://registry.npmjs.org
```

Результат по умолчанию — `dependency-graph.png` в текущем каталоге.
Путь можно изменить параметром `--output`.

## Параметры

- `--package` — имя анализируемого npm-пакета.
- `--repository` — URL npm-реестра или путь к JSON-файлу тестового графа.
- `--mode` — `registry` для реального npm-реестра или `test` для файла.
- `--output` — путь к результирующему PNG-файлу.

## Этап 1: конфигурация

Все заданные параметры печатаются при запуске в формате `ключ=значение`.
Приложение проверяет имя пакета, URL или путь к тестовому файлу, режим и
путь PNG. Ошибки сопровождаются сообщением и справкой по аргументам.

## Этап 2: сбор прямых зависимостей

В режиме `registry` приложение запрашивает `/<package>/latest` у заданного
npm-реестра и читает поле `dependencies` из JSON. Для scoped-пакетов имя
URL-кодируется. Обрабатываются HTTP-ошибки, ошибки соединения, неверный JSON
и неверный формат поля зависимостей.

```sh
./run.sh --package left-pad --repository https://registry.npmjs.org
```
